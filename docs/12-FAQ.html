Appendix

Versioned changes and known issues

Chapter 2 - Introduction to NEON

Updated the structure of NEON API calls to explicitly include the NEON API token in request headers (e.g., add_headers(\X-API-Token = NEON_TOKEN)).

Chapter 4 - PhenoCam

Previous PhenoCam ROI package xROI is no longer maintained. Updated to modern workflow using phenopix package.

The prerecorded guest lecture by Andrew Richardson (4.1.1.1) is missing. The video in section 4.1.1.1 currently is a placeholder.

Chapter 5 - Fluxes and Interoperability

Outdated dependencies caused the eddy4R package to be unusable. Section 5.6.9 from the first edition was removed.

Chapter 6 - NEON AOP

The rgdal package is retired and no longer supported by CRAN. Geospatial workflows were updated to utilize modern packages.

Chapter 7 - NASA EOS

Updated NASA AppEEARS API examples to reflect a more current R-based workflow, including revised HTTP POST requests, task submission, API endpoint construction, authentication token handling, and JSON request/response parsing. Migrated versions of data products, e.g., MOD11A2.006 to MOD11A2.061. Updated geospatial workflows using outdated packages (rgdal).

Chapter 8 - USGS

The USGS dataRetrieval package was significantly updated in 2026, causing changes to most previous function names previously included in edition 1 of the textbook. Continued changes to the API can be monitored at dataRetrieval status page.

The geoknife package was removed from CRAN and its associated service infrastructure is no longer reliably accessible, preventing the original workflow from being reproduced. Consequently, Section 8.16 from the first edition was removed.
